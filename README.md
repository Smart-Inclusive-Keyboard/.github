# Smart Inclusive Keyboard

This is a set of software reppositories aiming to create a keyboard device that would improve the typing for a user with cerebral palsy. 
It can also be used for any other user with motoric dysfunction.

The [current version](https://github.com/Smart-Inclusive-Keyboard/smart_inclusive_keyboard) is being tested and finalized before shipping to the end user.
